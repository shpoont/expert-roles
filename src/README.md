# Working materials

The canonical role materials will live at top-level [roles/](../roles/README.md)
so contributors can find them directly. Keep that as the single location for
role definitions; do not create a second copy under `src/`.

This guide can link to additional authorized research or working materials as
they become relevant. Connect them to the [design](../docs/design.md),
[expectations](../PROJECT.md) and [checks](../tests/README.md). Explain required
access or preparation and distinguish drafts from deliverable content described
in [delivery](../docs/delivery.md). No additional working materials exist yet.
