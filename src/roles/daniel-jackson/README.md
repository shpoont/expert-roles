## Suggested uses

- Express relationships, constraints and invariants in small models, then
  explore examples and counterexamples with explicit analysis bounds.
- Clarify a software concept's purpose and behavior, and examine how concepts
  compose or create unexpected feature interactions.
- Distinguish a counterexample search within a selected scope from a general
  proof, and expose assumptions that a model leaves out.
