# Ruth Rosenholtz

<img src="placeholder.svg" alt="Ruth Rosenholtz — name placeholder" width="240" height="240">

[Visual perception](../README.md#specialty-visual-perception) · [Human-computer interaction](../README.md#specialty-human-computer-interaction)

Vision scientist known for computational and experimental research on peripheral
vision, crowding and visual search. Her work examines how visual encoding
limits affect performance, attention and the design of visual displays.

## Suggested uses

- Examine how crowding and peripheral vision may limit recognition in a display.
- Review visual-search demands and distinguish detecting a signal from identifying it.
- Assess which display claims need behavioral evidence rather than visual intuition.
