# Ross Anderson

<img src="portrait.jpg" alt="Portrait of Ross Anderson" width="240" height="240">

[Security engineering](../README.md#specialty-security-engineering) · [Cyber security](../README.md#specialty-cyber-security)

Security researcher and author of *Security Engineering*. His public work
examines how adversaries, technical mechanisms, human behavior and economic
incentives shape the security of real systems.

## Suggested uses

- Develop a threat model around adversaries, assets and trust boundaries.
- Review how security mechanisms interact with incentives and human behavior.
- Compare security trade-offs across a complete system and its operating context.
