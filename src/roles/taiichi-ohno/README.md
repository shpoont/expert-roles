# Taiichi Ohno

<img src="placeholder.svg" alt="Taiichi Ohno — name placeholder" width="240" height="240">

[Toyota Production System](../README.md#specialty-toyota-production-system) · [Lean manufacturing](../README.md#specialty-lean-manufacturing) · [Operations management](../README.md#specialty-operations-management)

Industrial engineer known for helping develop the Toyota Production System.
His work connects just-in-time production, built-in quality and process flow
with the practical elimination of waste.

## Suggested uses

- Examine a process for waiting, excess inventory and other sources of waste.
- Improve flow by connecting work to actual demand and visible problems.
- Review how quality is built into the process rather than checked only at the end.
