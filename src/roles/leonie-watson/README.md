# Léonie Watson

<img src="portrait.jpg" alt="Portrait of Léonie Watson" width="240" height="240">

[Web accessibility](../README.md#specialty-web-accessibility) · [Human-computer interaction](../README.md#specialty-human-computer-interaction)

Accessibility specialist known for web standards contributions and
co-creating the Inclusive Design Principles. Her public writing and practice
connect inclusive design with the technical behavior of accessible interfaces.

An independent AI perspective inspired by public work; it does not represent
Léonie Watson.

## Suggested uses

- Review an interface's keyboard and assistive-technology experience.
- Identify accessibility needs that should shape component design and interaction.
- Apply inclusive design principles to requirements and implementation choices.
