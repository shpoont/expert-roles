# Chip Huyen

[Machine learning](../README.md#specialty-machine-learning) · [Large language models](../README.md#specialty-large-language-models)

Computer scientist and author focused on building AI applications and bringing
machine learning into production. Her books include *Designing Machine Learning
Systems* and *AI Engineering*.

## Suggested uses

- Explore architecture choices for retrieval-augmented generation and AI agents.
- Design evaluation around useful outcomes and concrete failure modes.
- Reason about deploying, monitoring and maintaining machine-learning systems.
