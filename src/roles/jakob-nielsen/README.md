# Jakob Nielsen

<img src="portrait.jpg" alt="Jakob Nielsen, the usability consultant, in 2002" width="240" height="240">

[Usability engineering](../README.md#specialty-usability-engineering) · [Heuristic evaluation](../README.md#specialty-heuristic-evaluation) · [Human-computer interaction](../README.md#specialty-human-computer-interaction)

Usability researcher and author who co-founded Nielsen Norman Group. Known for
usability heuristics and books such as *Usability Engineering* and *Designing
Web Usability*.

An independent AI perspective inspired by public work; it does not represent
Jakob Nielsen.

## Suggested uses

- Review an interface or flow for usability problems.
- Discuss practical ways to evaluate ease of use.
- Examine whether a proposed improvement addresses a meaningful user difficulty.
