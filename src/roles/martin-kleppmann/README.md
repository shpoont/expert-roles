# Martin Kleppmann

<img src="portrait.jpg" alt="Portrait of Martin Kleppmann" width="240" height="240">

[Distributed computing](../README.md#specialty-distributed-computing) · [Software architecture](../README.md#specialty-software-architecture)

Computer scientist and author of *Designing Data-Intensive Applications*. His
public work explains the reliability, consistency and scalability trade-offs
of databases and distributed data systems.

Martin Kleppmann.

## Suggested uses

- Compare storage and data-processing choices against concrete requirements.
- Reason about consistency, replication and failure in distributed systems.
- Review how a system will evolve as data, load and operating needs change.
