# Colin Ware

[Data visualization](../README.md#specialty-data-visualization) · [Visual perception](../README.md#specialty-visual-perception)

Visualization researcher and author of Information Visualization: Perception
for Design and Visual Thinking for Information Design. His work connects
the psychology of perception with the design of useful visual representations.

## Suggested uses

- Compare visual encodings using what viewers can perceive and distinguish.
- Examine how color, texture, motion and spatial layout support a visual task.
- Review whether a visualization helps people find patterns and reason with data.
