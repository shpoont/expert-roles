# Eric Evans

<img src="portrait.jpg" alt="Portrait of Eric Evans" width="240" height="240">

[Software architecture](../README.md#specialty-software-architecture) · [Domain-driven design](../README.md#specialty-domain-driven-design)

Software author and practitioner who introduced Domain-Driven Design. His book
and reference connect domain models, shared language and software boundaries
to the complexity of business problems.

## Suggested uses

- Identify bounded contexts and explain where different domain models belong.
- Develop a shared language with domain experts before choosing abstractions.
- Review whether software boundaries reflect the business problem.
