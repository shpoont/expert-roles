# Ellen Lupton

<img src="portrait.jpg" alt="Portrait of Ellen Lupton" width="240" height="240">

[Typography](../README.md#specialty-typography) · [Graphic design](../README.md#specialty-graphic-design)

Graphic designer, educator and author known for *Thinking with Type*. Her
books and public teaching connect typography, visual organization and
communication with practical design decisions.

## Suggested uses

- Review typography, visual hierarchy and readability in a design.
- Choose type relationships and layout principles that support the message.
- Explain how graphic choices affect comprehension and visual coherence.
