# Detail for project parts

Add a record when an approved role, workstream, evaluation or other part needs
more explanation than fits in [design](../design.md). Keep its purpose,
responsibilities, dependencies and relationship to the whole visible.

Link to the relevant [agreement](../../PROJECT.md),
[checks](../../tests/README.md), [explorations](../../mocks/README.md),
[materials](../../src/README.md) and [evidence](../../evidence/README.md).
No element-specific records or role schema are required by this initial scaffold.
