# Contributing to Expert Roles

The project is at the design stage. The catalogue is empty and the role format
and contribution terms are still being decided.

## Start a discussion

Open an [issue](https://github.com/shpoont/expert-roles/issues) describing:

- The expert perspective or role you want to add or improve.
- The tasks where it should help and the result a user should expect.
- The public methods, references or experience that would ground its guidance.
- A representative example and how we could assess whether it helps.

Distinguish an expert's documented methods from your own interpretation. Include
links to relevant sources and explain the intended use in your own words.

## Current contribution scope

Documentation corrections and design proposals are welcome. Agree the role
format, scope and contribution terms with the maintainer before submitting role
definitions, implementation code or copied material. There is no approved role
template or executable integration to extend yet.

Keep submissions readable from this public repository alone. Include only the
context needed to discuss the contribution and omit credentials, personal data
and private project information.
