# Models, examples and explorations

Use this location for authorized sample outputs, role comparisons, sketches or
other explorations before committing to a role design. None exist yet.

Explain each exploration's question, conditions, how to use it, what it
represents, limitations and findings. Link it to the [design](../docs/design.md),
relevant [expectations](../PROJECT.md), [checks](../tests/README.md) and retained
[evidence](../evidence/README.md). Keep illustrative output distinguishable from
an implemented or evaluated role.
